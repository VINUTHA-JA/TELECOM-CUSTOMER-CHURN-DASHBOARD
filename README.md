# TELECOM-CUSTOMER-CHURN-DASHBOARD
Telecom Customer Churn Analysis using Python, MySQL, and Power BI to identify churn trends and improve customer retention
Telecom Customer Churn Analysis

Project Overview

Analyzed telecom customer churn using Python, MySQL, and Power BI to identify churn patterns and improve customer retention.

Tools Used

* Python (Pandas)
* MySQL
* Power BI
* DAX

Key Insights

* Identified high-risk customer segments.
* Analyzed churn by contract type, internet service, and payment method.
* Created interactive dashboards and actionable business recommendations.

Objective

To support data-driven decision-making and improve customer retention.

How to View the Dashboard

1. Download the .pbix file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the report pages and interactive visualizations.
